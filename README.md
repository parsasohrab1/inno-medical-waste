# inno-medical-waste

**رهگیری پسماند بیمارستانی**

> وضعیت: **TRL 4** — نمونه‌ی آزمایشگاهی با اعتبارسنجی اجزا روی **داده‌ی مصنوعی** (بدون داده‌ی بیمار). برای ارزیابی بالینی یا میدانی آماده نیست. ← [مستندات TRL](docs/TRL.md)

## نیاز شناسایی‌شده
پسماند عفونی و خطرناک با ثبت و رهگیری ناقص.

## محصول
ثبت، رهگیری و گزارش‌دهی پسماند از تولید تا دفع.

## کاربران و ذی‌نفعان
مدیریت محیط بیمارستان، سازمان محیط زیست

## قابلیت‌های هدف
- ثبت وزن و نوع پسماند
- رهگیری با QR
- گزارش انطباق

## داده
وزن، نوع، بخش، شرکت حمل. در مراحل اولیه فقط داده‌ی مصنوعی یا بی‌نام‌شده استفاده می‌شود.

## ریسک‌ها و محدودیت‌ها
نیاز به ثبت میدانی؛ هماهنگی با پیمانکار.

## مسیر پیشنهادی
1. ✅ TRL 1 → 2: تعریف نیاز و معیار موفقیت (جدول معیارها در [docs/TRL.md](docs/TRL.md)).
2. ✅ TRL 3: نمونه‌ی آزمایشگاهی روی داده‌ی مصنوعی همراه با تست.
3. ✅ TRL 4: اعتبارسنجی اجزا در آزمایشگاه با تست‌های خودکار (CI روی هر push).
4. ⬜ TRL 5: اعتبارسنجی در محیط مرتبط با داده‌ی واقعی بی‌نام‌شده — نیازمندی‌ها در [docs/TRL.md](docs/TRL.md).

## یادداشت
این ریپو بخشی از مجموعه‌ی `inno-medical-*` برای دانشگاه‌های علوم پزشکی و وزارت بهداشت است. هیچ‌یک از خروجی‌ها جایگزین قضاوت بالینی نیست.

## راه‌اندازی سریع
```bash
pip install -r requirements.txt           # فقط numpy
export PYTHONPATH=src
python -m inno_medical_waste generate --out data/sample # تولید داده‌ی مصنوعی (قطعی با seed)
python -m inno_medical_waste validate                   # اجرای معیارهای TRL 4 روی ۳ seed
python -m inno_medical_waste demo
python -m unittest discover -s tests -v
```

## آنچه پیاده‌سازی شده
شناسه‌ی QR ۱۶ رقمی با ارقام کنترلی (mod 97)، رهگیری ۵ مرحله، ۶ قاعده‌ی انطباق، گزارش انطباق به تفکیک بخش.
