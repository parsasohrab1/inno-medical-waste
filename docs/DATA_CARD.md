# کارت داده — inno-medical-waste

- **منبع:** کاملاً مصنوعی؛ تولید با `python -m inno_medical_waste generate --seed N` (قطعی). هیچ داده‌ی بیمار، شخص یا مرکز واقعی در ریپو نیست.
- **نمونه‌ی ذخیره‌شده:** `data/sample/*.csv` (seed=0).
- **فرض‌ها:** قواعد قطعی هستند؛ بنابراین دقت ۱۰۰٪ نشان‌دهنده‌ی درستی پیاده‌سازی قواعد است نه اعتبار میدانی. محدودیت‌های زمانی/وزنی نمونه‌اند و باید از دستورالعمل رسمی گرفته شوند.
- **استفاده‌ی مجاز:** توسعه و آزمون نرم‌افزار. استفاده برای آموزش/ارزیابی مدل بالینی یا هر تصمیم واقعی مجاز نیست.
- **حریم خصوصی:** هنگام ورود داده‌ی واقعی باید بی‌نام‌سازی، مجوز اخلاق و توافق‌نامه‌ی اشتراک داده انجام شود.
